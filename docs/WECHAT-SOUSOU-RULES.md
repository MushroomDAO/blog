# 微信搜一搜优化规则（官方教程摘要）

来源：微信搜一搜官方「搜一搜优化教程」01（文章）、03（账号昵称/描述/菜单/认证）。
2026-09-24 整理。这里只记官方规则本身；我们怎么落地见文末「本仓库对照」。

## 一、文章标题：清晰、简洁、直接

- 标题要能看出文章主旨和关键信息，不隐瞒、不夸大。
- 禁止：标题党/震惊体、标题与正文无关、标题与开头大段内容无关、标题过短缺关键信息（「重要公告」「我的周记」）。
- 严格作弊处理：冒充入口、冒充官方账号，但正文给不出对应信息。
- 简明扼要，不堆修饰词、不堆符号、**不堆关键词**（「Dior迪奥三格缎面镶钻戴妃包 迪奥戴妃水钻包」）。
- **标题过长会难懂，并在搜索结果页被截断。**

## 二、正文：鲜明、详实、可用

1. 主题鲜明统一，围绕一个主旨展开；拼盘式内容会让搜索用户迷失。
2. 内容全面翔实，有具体论据；复杂主题有深度、有逻辑。
3. 表达简洁流畅、可操作；复杂问题用实例、配图、视频辅助理解。
   - 避免：图片模糊、变形、截断、白边、明显水印。
4. 鼓励原创、稀缺内容。**内容相同时优先展示「声明原创」的文章。**
   - 避免：搬运微信里已经大量存在的内容。
5. 以图片、视频、音频为主的文章，正文里要有足够的文字介绍，帮搜索引擎理解和召回。

## 三、排版：突出重点和层次

1. 适度用加粗、斜体、下划线、背景色标出主旨句或核心段落。
   - 避免：**加粗过多**（重点太多用户会迷失，搜索引擎也识别不出重点）；字号过大或过小；行距过窄或过宽。
2. 合理分段，给段落加小标题或重点句。
   - 避免：正文不分段；**广告营销、小编体内容过多且放在正文之前**。

## 四、账号：昵称、描述、菜单、认证

- **昵称**：有品牌性、特异性。个人号用「字词组合」或「个人名 + 字词」。不要用通用词（手机、健康、正能量等），搜索会定向打压。严禁仿冒、地名、夸大、乱码/异体字。
- **描述**：写清账号主体介绍、账号功能、账号特色。严禁堆砌关键词、仿冒、蹭热点。
- **菜单**：每项菜单都是具体、可理解的功能名（「挂号」好过「医院服务」）；用一二级菜单把主要功能铺全；持续维护，避免死链；避免「办事大厅」这类宽泛名；不要堆同义词做 SEO。
- **认证**：认证后权威度得分更高（个人主体也能认证）；有商标的可以做商标认证；视频号可做兴趣/职业认证。

## 本仓库对照（2026-09-24 基于最近 60 篇统计）

| 规则 | 现状 | 差距 |
|---|---|---|
| 标题简洁、不堆关键词 | 标题中位 56 字、最长 104 字，60/60 篇超过 30 字；常见「实体：A，B，C 数字」多段式 | 大 |
| 摘要 | `index.js` 把 description 硬截前 60 字当 digest，description 中位 219 字，60/60 篇摘要在句中被截断 | 大 |
| 加粗适度 | 中位 5.7 处/千字，单篇最多 64 处；加粗还渲染成主题色 | 中 |
| 正文前不放营销内容 | 正文最前面有「🍄 原文发布于 blog.mushroom.cv」水印条 | 小 |
| 标题与开头相关 | 开头常以 `owner/repo`、许可证、star 数起笔，而不是先说「这是什么」（正文无 H1 重复问题，初次统计误把代码块注释算成了 H1） | 中 |
| 声明原创 | 草稿已带 `original_article_type=1` | 需在后台确认是否生效 |
| 图文有文字介绍、分段、小标题 | H2 中位 9 个，正文中位约 3900 字，图片均有 alt | 基本达标 |
| 菜单具体可用 | 只有「资源」「About」两项，都指向 Web3 时期的旧文 | 大 |

## 落地（2026-09-24）

- frontmatter 新增 `wechatTitle`（≤30 字）、`wechatDigest`（≤54 字）；pubDate 在 2026-09-25 及之后的文章必填，旧文不补。
- `pipeline/m2/wechat-lint.js`：`scripts/publish-blog.sh` 第 1 步调用，缺字段或超长就拦截；加粗过多、标题堆叠、标题党用词只警告。
- `pipeline/m2/index.js` 优先用 `wechatTitle`/`wechatDigest`；没填时摘要在句末截断，不再硬切 60 字。
- 「原文发布于 blog.mushroom.cv」从正文前挪到正文后。
- 写作规则（开头第一句先说是什么、每个 H2 小节最多 1 处加粗、至少一段自己的实测）写进了 `.agents/skills/blog-publisher/SKILL.md`。
