# 网站变现计划：每天 1 美元

立项：2026-09-24　目标：AdSense 等合规收入稳定达到 **1 美元/天**（约 30 美元/月）

## 核心判断

合规收入的链条是：真实内容 → 真实搜索/社交流量 → 真实广告展示与点击。

**关键前提是海外流量。** 中国大陆访客基本加载不出 Google 广告（googlesyndication 被墙），
即使加载出来单价也很低。按海外 RPM 约 3 美元估算，每天约需 **300 次海外浏览**。

2026-09-24 实测近 30 天流量（Cloudflare，采样 1:10）：约 1.5 万次浏览，
新加坡 43%、中国大陆 30%、美国 7%、香港 5%、日本 4%，**大陆以外约 70%**。
新加坡占比高，其中可能有不少是挂代理的国内读者或机房爬虫，需要结合 AdSense 按国家的报表核实。

> 注：9 月 22 日那份统计快照因为 Cloudflare 临时把采样调到 1:1000 而严重失真（只显示中国），
> 现在抓取脚本遇到这种情况会拒绝覆盖。

正文内的广告由我们手动控制。

| 类型 | 建议 | 理由 |
|---|---|---|
| Anchor ads | 保留 | 贴边，不挡正文 |
| Widescreen anchor ads | 保留 | 桌面版锚定广告，主力流量在桌面 |
| Side rails ads | 保留 | 宽屏两侧留白本来就空着，不影响阅读 |
| Vignette ads | 保留 | 只在翻页之间出现，手机流量小，影响有限 |
| Ad intents | **屏蔽** | 会往正文里自动插链接，技术文章显得像垃圾站 |
| Banner ads | **屏蔽** | 正文内已有 3 个手动广告位，再自动插会过密 |
| Fine-tune banner ads | **屏蔽** | 同上 |
| Widescreen vignette ads | **屏蔽** | 桌面全屏插页会打断长文阅读，影响回访 |
| Vignette ad frequency | **屏蔽** | 保持默认频率，不让 Google 自动调高 |

保留的格式先观察 2 周，看 RPM 和跳出率再调整。

## 明确不做

自己点广告、买流量、流量交换、诱导点击的文案（比如"点广告支持我"）、自动化账号批量发帖。
这些都会导致 AdSense 封号或者被社区拉黑。
