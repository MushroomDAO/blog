# 网站变现计划：每天 1 美元

立项：2026-09-24　目标：AdSense 等合规收入稳定达到 **1 美元/天**（约 30 美元/月）

## 核心判断

合规收入的链条是：真实内容 → 真实搜索/社交流量 → 真实广告展示与点击。

**关键前提是海外流量。** 中国大陆访客基本加载不出 Google 广告（googlesyndication 被墙），
即使加载出来单价也很低。按海外 RPM 约 3 美元估算，每天约需 **300 次海外浏览**。

2026-09-24 实测近 30 天流量（Cloudflare，采样 1:10）：约 1.5 万次浏览，
新加坡 43%、中国大陆 30%、美国 7%、香港 5%、日本 4%，**大陆以外约 70%**。
新加坡占比高，其中可能有不少是挂代理的国内读者或机房爬虫，需要结合 AdSense 按国家的报表核实。

> 注：9 月 22 日那份统计快照因为 Cloudflare 临时把采样调到 1:1000 而严重失真（只显示中国），
> 现在抓取脚本遇到这种情况会拒绝覆盖。

**自动广告设置（B2）**：原则是不给读者"广告滥用"的感觉。文章页已有 2 个手动广告位
（正文中段 + 文末），首页和 /blog 列表各 1 个。自动广告和手动广告位**并存**，不会替换或挪走手动广告位，
但格式开多了会叠加。

注意区分两个地方：「优化 → 实验 → Blocked experiments」只是禁止 Google 自动做哪些实验，
**真正决定显示哪些格式的开关在「广告 → 按网站 → 编辑（铅笔图标）」里**。

| 格式 | 建议 | 理由 |
|---|---|---|
| Anchor ads（含宽屏） | 开 | 贴在屏幕底部的一条，可关闭，不挡正文 |
| Side rails ads | 开 | 只在两侧有空白的宽屏上出现；屏幕不够宽 Google 自己不放 |
| Vignette ads（含宽屏） | **关** | 点站内链接时弹出的全屏广告，最容易让人觉得"广告滥用"，会伤害回访 |
| In-page / Banner ads | **关** | 正文里已有手动广告位，再自动插会过密 |
| Ad intents | **关** | 会往正文里自动插广告链接，技术文章显得像垃圾站 |
| Ad load（广告负载滑块） | 调到最低 | 控制自动广告总量 |

观察 2 周：看 /analytics 的「约 N 页/次访问」和 AdSense 的 RPM。每次访问的页数明显下降，就把 Side rails 也关掉。

## 明确不做

自己点广告、买流量、流量交换、诱导点击的文案（比如"点广告支持我"）、自动化账号批量发帖。
这些都会导致 AdSense 封号或者被社区拉黑。
