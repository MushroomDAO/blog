## M1 — 语义检索 / 智能推荐功能
目标：用户输入一段自然语言诉求，能在博客几百篇文章里找到相关内容，并看到匹配理由。

- **F1.1 关键词/静态检索基线（Phase 0A）** — Pagefind 构建时索引 + 搜索页面 + 评测查询集，
  零在线 AI 成本跑通完整体验，同时建立后续对比的基线数据。
- **F1.2 离线向量效果验证（Phase 0B）** — 用同一批评测查询离线对比"关键词 vs 向量 vs 融合"，
  产出是否值得进入 Phase 1 的决策依据（不上线）。
- **F1.3 语义检索上线（Phase 1）** — 依赖 F1.2 的裁定为"go"：Cloudflare Vectorize +
  Workers AI（`bge-m3`）+ `/api/search`，文章级聚合去重、双语路由、基本防滥用。
- **F1.4 自动更新与增强（Phase 2）** — 依赖 F1.3 完成：发布流程 hook 触发增量索引、
  Cron Trigger 每日对账；可选：reranker、LLM 生成的一句话匹配理由。
