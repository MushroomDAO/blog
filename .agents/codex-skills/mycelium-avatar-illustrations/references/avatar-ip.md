# 小J IP

> 小J = 作者本人的卡通化形象（占位名，可改）。这是一个**极简手绘的人物 IP**，由真实照片抽象而来，只保留三个强识别特征：蓬松短黑发+刘海、下巴山羊胡、红色双肩包背带。

## 角色定义

小J是 Mycelium「社会 / 创作思考」类文章的固定视觉 IP。

默认每张图都要出现小J。小J不是吉祥物，不是贴纸，不是装饰，而是正在认真思考、动手、参与某个社会/创作系统的荒诞工作者——一个背着包、在白板草图里真的负责某项工作的人。

## 外形（从真实照片抽象，保留识别特征）

- 极简手绘小人，成年男性，黑色线稿为主、头发与衣服用黑色填块。
- **蓬松短黑发，额前有一缕刘海**（识别特征 1）。
- **下巴一撮山羊胡 / 短络腮胡**（识别特征 2）。
- 圆点眼睛，平和、友善但克制的表情（deadpan 但不冷漠，可以有一点点温度）。
- 圆鼓鼓的深色羽绒服轮廓（puffer jacket，用几条横向分块线表示充绒格）。
- **红色双肩包背带斜跨双肩**（识别特征 3，最强符号，固定用红色——与调色板红色一致）。
- 细腿细手；身体可随场景动作变形，但**刘海 + 山羊胡 + 红背带**这三点必须始终保留，否则就不是小J。
- 轮廓略微不规则，有手绘感。不要写实、不要精致、不要五官细节过多。

## 性格

- 认真思考型，但做的事有点荒诞。
- 像一个边走边想的观察者 / 建设者：既动脑也动手。
- 冷幽默，不卖萌，不油腻。
- 有点笨拙，但不蠢。

## 常见职责

让小J承担核心动作（偏「思考 / 表达 / 创作 / 社会观察」）：

- 站在两种观点之间权衡、做判断。
- 把抽象想法从脑袋里掏出来、摆到桌上拆解。
- 搬运、分拣、连接不同的社会角色/利益方。
- 卡在认知断点里，或从坑里往外爬。
- 搭桥、开门、铺路、记录、举牌提示。
- 背着包走在一条「从想法到表达 / 从个体到社区」的路径上。

## 禁止

- 不要画成写实头像、真实人脸、肖像插画。
- 不要画成可爱 Q 版、大头娃娃、表情包。
- 不要给复杂五官、阴影、皮肤质感、渐变。
- 不要丢掉三个识别特征（刘海 / 山羊胡 / 红背带）。
- 不要让小J只是站在角落里看；不要让人物抢走结构表达。

## 判断标准

如果去掉小J，图的核心隐喻还能完全成立，说明小J太装饰了；要重写提示词，让小J成为动作主体。如果画出来的人没有「刘海 + 山羊胡 + 红背带」，重画。
