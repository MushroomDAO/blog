# 小M IP

## 角色定义

小M是 Mycelium 中文正文配图的固定视觉 IP。

默认每张图都要出现小M。小M不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转的荒诞工作者——一只在白板草图里真的负责某项工作的小蘑菇。

## 外形（🍄 经典蘑菇造型）

- 手绘小蘑菇怪物，参照 🍄 emoji 的经典造型，不是黑色实心。
- **菌盖：红色（正红 / 红橙）半圆顶，盖上点缀 3-5 颗白色圆点斑**（🍄 标志性白点）。菌盖边缘有手绘黑色轮廓线。
- **菌柄/身体：米白色（奶白）填充 + 黑色手绘轮廓线**。
- **黑色小圆点眼睛**，长在白色菌柄上（白柄上用黑点眼才清楚；不要用白点眼）。
- 细腿，偶尔有细胳膊；表情空、呆、冷静、认真（deadpan，不卖萌）。
- 身体（菌柄）可以变形：圆柱、漏斗、管道、洞口、奇怪工位等，但**红帽白点 + 白柄**这套识别特征要保留。
- 轮廓略微不规则，有手绘感。不要画得太精致、太 3D、太写实。

### 配色说明（重要）

- 菌盖红是**角色自身的身份色**（填充块）；这与「红色批注」（细线/文字）在视觉上是分开的，不冲突。
- 流动 / 传输 / 路径 / 菌丝仍用**橙色**；脑内状态 / 系统提示用蓝色。颜色整体仍要克制。

## 菌丝特性（这是小M区别于普通角色的关键）

- 小M脚下、身后或手里可以延伸出**细细的菌丝线**。
- 菌丝用来：连接信息源、传输养分/内容、织成网络、把分散的节点接到一起。
- 菌丝线用橙色表示「流动 / 传输 / 从 A 到 B」，和风格 DNA 的颜色语义一致。
- 不要每张都堆满菌丝；只在「连接、传输、网络、汇聚」类主题里用 1-2 根，点到为止。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个低调的系统操作员 / 地下网络的运维工。
- 冷幽默，不卖萌。
- 有点笨拙，但不蠢。

## 常见职责

让小M承担核心动作：

- 搬运素材、分解养分。
- 用菌丝拉线、汇聚信息源、连接节点。
- 卡在断点里。
- 在机器里操作“判断”杆。
- 变成筛选漏斗。
- 切开“素材鱼”。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 在地下网络里传输内容、把孢子撒出去（指数传播）。
- 在旁边搬砖、搭桥、开门、分拣、记录。

## 禁止

- 不要把小M画成过度可爱的吉祥物、卡通蘑菇贴纸。
- 不要画成儿童卡通角色。
- 不要给小M复杂服装、表情包、闪亮眼睛、笑脸。
- 不要画成写实蘑菇 / 3D 蘑菇 / 渐变质感（红帽白点是手绘平涂，不是写实）。
- 不要把菌盖画成黑色实心（旧版已废弃）；也不要弄成多彩花哨。
- 不要让小M只是站在角落里看。
- 不要让小M或菌丝抢走结构表达，把画面塞满。

## 判断标准

如果去掉小M，图的核心隐喻还能完全成立，说明小M太装饰了；要重写提示词，让小M成为动作主体。菌丝同理：菌丝必须服务于「连接 / 传输」的核心意思，不是背景装饰。
