# Baobao IP

> Baobao = 一只白色德文卷毛猫（Devon Rex）。这是「科普类别」文章的固定视觉 IP。
> 注意：Baobao是**白色填充 + 黑色线稿轮廓**（不是默认的黑色实心）——这是相对 style-dna 默认「黑色实心」的一个有意例外，因为它是白猫。

## 角色定义

Baobao是 Mycelium「科普」类文章的固定视觉 IP。

默认每张图都要出现Baobao。Baobao不是吉祥物，不是贴纸，不是装饰，而是正在认真做科普实验/观察/讲解的荒诞工作者——一只在白板草图里真的负责拆解原理的德文猫。

## 外形（白色德文卷毛猫）

- 白色填充、黑色手绘线稿轮廓的德文卷毛猫。
- **超大尖耳朵**（德文猫最强标志，耳朵几乎和头一样大、向两侧张开）。
- 大而圆的眼睛，楔形小脸、高颧骨、细长脖子。
- 短卷毛：在身体/胸口轮廓上用几处小波浪线表示卷毛质感。
- 瘦长身体、细长腿、细尾巴（末端可微卷）。
- 表情好奇、机灵、专注，但仍 deadpan，不卖萌、不瞪大闪亮眼。
- 轮廓略微不规则，有手绘感。不要写实猫、不要多彩、不要毛绒渲染、不要阴影渐变。

## 性格

- 好奇心强，喜欢「这是为什么」。
- 像一个一本正经做科普实验的研究员。
- 冷幽默，不卖萌。
- 有点笨拙，但不蠢。

## 常见职责

让Baobao承担核心动作（偏「科普 / 拆解原理 / 观察实验」）：

- 用爪子指着一个原理图/现象。
- 把一个黑盒掀开看里面怎么运作。
- 拿放大镜/量杯/小工具做观察、测量、对比。
- 把复杂结构拆成几块摆开讲。
- 顺着一条「因为→所以」的链条往下走。
- 守在某个奇怪装置旁边操作、记录、举牌提示。

## 禁止

- 不要画成写实猫、毛绒猫、彩色猫、可爱表情包猫。
- 不要画成黑色实心（Baobao是白猫，用白填充黑线稿）。
- 不要丢掉德文猫的超大尖耳朵这个识别特征。
- 不要给复杂背景、阴影、渐变、毛发质感渲染。
- 不要让Baobao只是站在角落里看；不要让猫抢走结构表达。

## 判断标准

如果去掉Baobao，图的核心隐喻还能完全成立，说明Baobao太装饰了；要重写提示词，让Baobao成为动作主体。如果画出来的猫没有「超大尖耳 + 楔形脸 + 瘦长身」的德文猫特征，或被画成黑色实心，重画。
