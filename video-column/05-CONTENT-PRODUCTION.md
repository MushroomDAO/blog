# 05 · 内容生产管线与工具选型

> 目标：**一人，每天一条 5–7 分钟视频**，从"选题"到"上架带 1 分钟预览的成片"全流程 ≤ 90 分钟。
> 原则：**复用博客已有产能**（文章即脚本源）+ **复用你已掌握的本地视频工具栈**（零/低云成本）。

---

## 0. 核心洞察：视频是文章的"落地版"，不是新内容

你已经在**每天写博客文章**。视频栏目不应该是"再造一份内容"，而是把已有文章**转成手把手落地版**：文章讲"是什么/为什么"，视频讲"照着做一遍"。

这决定了整条管线的形态：**文章 → AI 拆脚本 → 录屏跟做 → 配音配字幕 → 剪 60s 预览 + 完整版 → 上架**。文章和视频天然一对一呼应（正是需求里的"部分视频和 blog 文章呼应"）。

```
已有文章 (src/content/blog/*.md)
      │  ← 复用，不重造
      ▼
 [1] AI 生成视频脚本 + 分镜表 (shot list)
      ▼
 [2] 录屏跟做 (screencast) + 真人/AI 旁白
      ▼
 [3] Whisper 字幕 + 轻剪 (去填充词/加 overlay)
      ▼
 [4] 导出：完整版 MP4 + 自动切 60s 预览片
      ▼
 [5] 上传 Cloudflare Stream → 拿 videoId → 写进文章 frontmatter
```

---

## 1. 五个环节的工具选型

### [1] 脚本 + 分镜：Claude Code（零成本）

输入文章 markdown，让 Claude 直接产出"可照读的口播稿 + 屏幕操作分镜表"。这是你最擅长的环节，固化成一个 skill 即可。

**产出模板（每条视频一份 `script.md`）：**

```markdown
# 视频脚本：<工具名> 5 分钟上手
关联文章: <slug>
目标（一句话）: 看完你能 <达成某个具体结果>
时长目标: 6:00

## 钩子 (0:00–0:20) —— 免费预览段就靠它
<一句话痛点 + 一句话承诺，必须在 60s 预览内讲完价值>

## 步骤 1 (0:20–1:40)  [屏幕: 终端/浏览器操作]
口播: ...
操作: 敲这条命令 `...`

## 步骤 2 ...
## 收尾 + CTA (5:30–6:00)
口播: 完整代码在关联文章，会员本月免费额度还剩 N 条
```

> ⚠️ **预览段设计是商业核心**：前 60 秒必须"讲清价值、给出钩子、但不给完整解法"。脚本阶段就要把"付费墙"卡在 1:00 这个点上——预览讲"能解决什么问题"，完整版讲"具体怎么做"。

### [2] 录制 + 旁白：分两条路线

| 路线 | 工具 | 适用 | 成本 |
|------|------|------|------|
| **A · 真人录屏**（推荐起步） | macOS QuickTime / OBS 录屏 + 你自己讲 | 代码演示、终端操作 | 0 |
| **B · AI 全自动** | [html-video](https://blog.mushroom.cv/blog/html-video-nexu-usage-guide/)（丢链接→MP4）或 [OpenMontage](https://blog.mushroom.cv/blog/openmongage-ai-video-studio-guide/)（脚本→成片） | 概念讲解、无需真实操作 | ~$1.3/条 |

**起步强烈建议路线 A**：代码/工具类视频，真实录屏 + 真人声音**可信度最高**，观众要的是"看你真的跑通一遍"。AI 全自动适合做"概念科普"补充，或你没空真人录时兜底。

> 复用你已写过的栈：真人配音嫌累时，用 **VidDub 的 CosyVoice2** 本地配音；需要多语言版用它的 Whisper→翻译→配音链路。

### [3] 字幕 + 轻剪：video-use（Claude Code 自然语言剪辑）

复用你博客写过的 [video-use](https://blog.mushroom.cv/blog/video-use-ai-video-editor-claude-code/)：自然语言描述剪辑任务，AI 自动**去填充词、生成字幕、加 overlay、调色**。

```
"把 raw.mp4 去掉所有'嗯/那个'，加中文硬字幕，
 在讲步骤时右上角叠命令行 overlay，输出 final.mp4"
```

字幕务必**硬烧进画面**（burned-in）——移动端和被二次传播时字幕不丢；同时留一份 `.srt` 供后续多语言。

### [4] 双输出：完整版 + 60 秒预览片

一次导出两个文件：
- `full.mp4` — 完整成片
- `preview.mp4` — 前 60 秒（`ffmpeg -t 60`，或用 Cloudflare Stream 的 `clip` 能力在服务端切，见架构文档，避免完整版流出）

**优先用 Cloudflare Stream 服务端切片**：完整版永不下发给未付费用户，预览由 Stream 动态生成，安全性最高。本地 ffmpeg 切预览是降级方案。

### [5] 上传 + 挂载：Cloudflare Stream → 文章 frontmatter

上传 `full.mp4` 到 Cloudflare Stream，拿到 `videoId`，写进关联文章的 frontmatter：

```yaml
video:
  streamId: "<cloudflare-stream-uid>"
  durationSec: 372
  priceUSDC: 0.15          # 1 元起 ≈ $0.15
  priceAPNTs: 10
  previewSec: 60
  goal: "10 分钟用 X 工具搭好 Y"
```

博客构建时，Astro 组件读到 `video` 字段就在文章下渲染**播放器 + 付费墙岛**（见架构文档 §前端）。

## 2. 每日 90 分钟 SOP（可交给助理/以后半自动化）

| 时段 | 动作 | 工具 | 耗时 |
|------|------|------|------|
| T+0 | 选定当天关联文章，跑脚本 skill | Claude Code | 10 min |
| T+10 | 顺脚本录屏 + 口播（一条过，不追求完美） | QuickTime/OBS | 20 min |
| T+30 | 自然语言剪辑 + 字幕 | video-use | 25 min |
| T+55 | 导出 full + 生成预览 | ffmpeg / Stream | 10 min |
| T+65 | 上传 Stream，填 frontmatter，本地 preview | Stream + 博客 | 15 min |
| T+80 | `publish-blog.sh` 发文（视频随文上线） | 现有脚本 | 10 min |

**产能护栏**：单条卡在完美主义会毁掉日更。规则——**一条过、6 分钟硬上限、当天不发就废**。宁可粗糙可用，不要精致但断更。

## 3. 选题库与排期（保证"持续创作"）

选题**不用另找**——直接从两个已有源头拉：

1. **存量文章回填**：`src/content/blog/` 里已有大量工具类文章，每篇都能出一条落地视频。先把高价值的排进队列。
2. **每日新文章**：你本来就日更文章，写完顺手出视频。

维护一个 `video-column/BACKLOG.md`（或用 Seeder 任务看板）：

```
| 日期 | 关联文章 slug | 视频目标 | 状态 | streamId |
|------|--------------|---------|------|----------|
| 07-07 | google-search-trends-mcp-guide | 10分钟接好 Trends MCP 并跑第一个查询 | 待录 | - |
| 07-08 | free-google-trends-mcp-studio-guide | 搭双-MCP 每日趋势简报 | 待录 | - |
```

**内容三大主线**（对应需求里的定位）：
- **效率工具** — MCP/CLI/Agent 工具的落地使用
- **商业工具** — 选品、趋势、增长、变现类工具
- **训练自己的模型** — 本地微调、数据准备、评测的心得实操

## 4. 质量基线（付费内容的底线）

付费视频和免费文章不同——**用户花了钱，必须"看完真能做到"**。每条上架前自检：

- [ ] 目标单一且明确（一句话说清"看完你能干什么"）
- [ ] 60 秒预览讲清了价值、留了钩子、没剧透解法
- [ ] 所有命令/代码在关联文章里可复制（视频不是唯一载体）
- [ ] 真的从零跑通了一遍（不是空讲）
- [ ] ≤ 7 分钟，无废话
- [ ] 字幕硬烧、移动端可读

## 5. 成本核算（单条 & 每月）

| 项 | 路线 A（真人） | 路线 B（AI） |
|----|--------------|-------------|
| 脚本 | $0 (Claude Code) | $0 |
| 录制/生成 | $0 (自录) | ~$1.3 (OpenMontage) |
| 剪辑字幕 | $0 (video-use 本地) | $0 |
| 配音 | $0 (真人) 或本地 CosyVoice2 | 含在生成里 |
| 托管/分发 | Cloudflare Stream 按分钟计费（见架构文档，量小近乎免费） | 同 |
| **单条边际成本** | **≈ $0** | **≈ $1.3** |

日更一个月 30 条，路线 A 几乎零边际成本——**这套栈的价值就是把"日更付费视频"的成本压到接近零**，让 1 元/条、7 元/月会员的定价能成立且盈利。

## 6. 与加密/会员/积分系统的接口

内容生产只负责产出 `full.mp4` + `streamId` + frontmatter 元数据。**付费墙、会员额度扣减、aPNTs 积分、任务发放与 AI 评测**全部由后端服务处理——见：

- `02-ARCHITECTURE.md` — 系统架构与技术选型
- `03-MODULES.md` — 模块拆分（含支付/会员/积分/任务模块）
- `04-DATA-MODEL.md` — 数据模型与 API

内容生产者（你）只需保证：**每条视频有 streamId、有 60s 预览、frontmatter 填了价格与目标**。剩下的系统自动接管。
