## Standard Review Lens

Each daily brief prioritizes topics using these questions:

1. What real SME pain does this solve?
2. Why is the topic timely?
3. What can become a free/open-source component?
4. What can become a paid managed or vertical service?
5. Is it suitable for a deep Blog, short video, or demo?
6. Does it strengthen the SME AI Node architecture?

## Target Architecture

The recurring product thesis is a local-first SME AI Node with:

- Company Context
- Connectors
- Permissions / Identity / Secrets
- Skills and Workflows
- Human Approval / Audit
- Local + Cloud model routing
- Vertical Operating Packs
- Usage, ROI and Evaluation

New reports are appended as `YYYY-MM-DD.md`.
