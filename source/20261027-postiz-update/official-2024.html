Postiz v1.6.7 - more social media platforms

Nevo David

October 26, 2024

Hi, welcome to the first Postiz newsletter,

A few versions have been released lately, so let’s review the newest features!

  • Add Bluesky, Mastodon, Discord, Slack, and X providers.

  • Team fixes - you can now invite your team members. We have fixed most of the bugs.

  • Improve the refresh token mechanism (even for more complicated ones like Facebook and Instagram)

  • Self-Hosted: Generic Email Provider & Easier installation experience (drop the default Resend and add a nodemailer option!)

  • Self-Hosted: Add multiple options for uploading files (locally / R2) - working on S3.

  • Self-Hosted: Uploading fixed for smaller files.

  • Self-Hosted: a lot easier deployment, run docker-compose without changing almost any parameter.
