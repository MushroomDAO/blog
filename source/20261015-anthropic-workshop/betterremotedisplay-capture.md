BetterRemoteDisplay is an independent macOS menu-bar virtual-display utility, unrelated to Anthropic workshops. It selects the remote Mac desktop logical resolution using Apple-device presets, custom dimensions, portrait/landscape and HiDPI2x. It targets macOS14+ on AppleSilicon orIntel, with Xcode26+/Swift6 forsourcebuilds.
GitHub/source builds are described as free and complete; the AppStoreedition is limited toone device until a one-timepurchase enables additionaldevices/customresolutions. It uses the private CoreGraphics CGVirtualDisplay interface, so futuremacOScompatibility is notguaranteed. No repository images were found in README/tree.
