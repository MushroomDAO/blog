# Dataset Card — qora-voca-zh training data

## Summary

A fully synthetic Mandarin speech dataset built for training a small TTS model. **No human recordings, no third-party copyrighted text.**

| | |
|---|---|
| Corpus | 10,696 sentences (`data/corpus/sentences.jsonl`) |
| Generated audio | ~30,204 utterances (3 voices × corpus) |
| Accepted after QC | **28,231 utterances / 25.25 hours** |
| Voices | F2, M2, M3 (synthetic designs) |
| Sample rate | 24 kHz mono |
| Text license | CC BY 4.0 |
| Audio/weights license | Apache-2.0 (audio not redistributed in-repo; reproducible via scripts) |

## Corpus composition

1. **Template × slot combinatorics** (majority): everyday domains — weather, food, travel, work, family, shopping, health, technology, study, feelings, dialogues. Slots are common words so pypinyin dictionary coverage stays high. Lengths 5–45 characters. Deterministic seed 20261116, deduplicated.
2. **Classical poetry** (minority): Tang/Song dynasty verses (public domain, >1000 years old), e.g. 李白《静夜思》、孟浩然《春晓》、王之涣《登鹳雀楼》. Included for tonal/rhythmic diversity.

Every sentence is original template output or public-domain verse. The `source` field reads `template+poetry`.

## Voice design

Each voice is a **text-described timbre** rendered by Qwen3-TTS VoiceDesign / 1.7B Base — not a clone of any real person:

- **F2:** 一位二十多岁的年轻女性，音色清亮温柔，普通话标准，语速适中，吐字清晰，语气自然亲切，像电台播音员。
- **M2:** 一位三十多岁的成熟男性，音色低沉浑厚，普通话标准，语速平稳，吐字清晰，语气沉稳自然，像新闻主播。
- **M3:** brighter, more articulate young male; selected from designed candidates by faster-whisper CER + spectral clarity screening (design 1, seed 20261131).

Reference prompts and ASR verification (CER = 0 for all three) are recorded in `data/voices/voices.json`; reference audio in `data/voices/{F2,M2,M3}.wav`.

## Generation pipeline

1. `scripts/build_corpus.py` → sentences
2. `scripts/design_voices.py` / `design_voice_m3.py` → voice references (Qwen3-TTS)
3. `scripts/generate_audio_zh.py` → per-sentence audio with the corresponding voice reference (Qwen3-TTS 1.7B Base, `x_vector_only_mode=False`, reference text supplied)
4. `python -m tiny_voca.annotate` → Mandarin CTC forced alignment (`lyonlu13/wav2vec2-large-zh-singing-phoneme-ctc`) + QC
5. `python -m tiny_voca.prepare` → acoustic features (mel, F0, voicing, energy)

## Quality control

Gates (from `data/annotated-v3/summary.json`):

- max weak-phone fraction 0.25
- min token probability 0.5
- max phone frames 70
- min vowel voiced fraction 0.35
- speaking rate 4–30 phones/s

Rejections: 1,973 of 30,204 (6.5%), overwhelmingly `vowels_not_voiced` (1,965); remainder weak alignment / low confidence / overlong phone.

Accepted split:

| Split | Utterances | Hours | F2 | M2 | M3 |
|---|---|---|---|---|---|
| train | 28,058 | 25.097 | 10,038 | 8,290 | 9,730 |
| validation | 86 | 0.075 | 31 | 25 | 30 |
| test | 87 | 0.078 | 32 | 24 | 31 |

Median token probability 0.763; median phones/s 15.5; median vowel-voiced fraction 0.737.

## Licensing & provenance

- **Text:** CC BY 4.0 (templates original to this project; poetry public domain).
- **Synthetic audio:** generated by Qwen3-TTS (Qwen license applies to the generator; the generated audio is released under Apache-2.0 with this project). Audio files are **not** committed to the repo (size); the full pipeline is reproducible from the scripts and the fixed seeds.
- **Aligner:** `lyonlu13/wav2vec2-large-zh-singing-phoneme-ctc` — used offline for annotation only, not redistributed, not needed for inference.
- **No human voice data** of any kind is used.

## Reproduction

```bash
pip install -e ".[prepare,annotate,generate]"
python scripts/download_assets.py        # aligner weights
python scripts/build_corpus.py
python scripts/design_voices.py
python scripts/design_voice_m3.py
python scripts/generate_audio_zh.py
python -m tiny_voca.annotate --help
python -m tiny_voca.prepare --help
```

See `docs/training.md` for exact commands and hyperparameters.
