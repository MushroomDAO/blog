# Model Card — qora-voca-zh

## Model details

- **Name:** qora-voca-zh v1.0.0
- **Type:** Text-to-speech, Mandarin Chinese only
- **Architecture:** Feed-forward transformer + pitch-driven source-filter synthesizer (no neural vocoder). Fork of [tiny-voca](https://github.com/n4ze3m/tiny-voca).
- **Parameters:** 4,532,299 (speech model; the source-filter head itself is 25,862 parameters)
- **Voices:** 3 — `F2` (young female, bright and gentle), `M2` (mature male, deep and steady), `M3` (young male, bright and articulate)
- **Output:** 24 kHz mono waveform, float or 16-bit PCM
- **Limits:** 512 tokens / 3000 frames per utterance (~32 s); longer text is split automatically by `speak_text`
- **License:** Apache-2.0
- **Weights:** `release/qora-voca-zh.pt` (17.3 MB), `release/onnx/model.onnx` (21.4 MB)

## Intended use

Offline Mandarin TTS on commodity hardware: reading assistants, IVR prompts, accessibility, embedded/CPU deployments, education. Real-time on CPU (≈50× faster than real time via ONNX Runtime on a desktop CPU).

**Out of scope:** English or other languages, dialects, code-switching, voice cloning, singing. The model refuses text with no pronounceable Chinese content.

## Training data

25.25 hours of synthetic Mandarin speech (28,231 utterances passing QC), generated by Qwen3-TTS from a 10,696-sentence self-built corpus (template combinatorics + classical Tang/Song poetry, public domain). No human recordings and no third-party copyrighted text are used. See `docs/dataset-card.md`.

## Training procedure

- **Hardware:** single NVIDIA RTX 3060 12 GB
- **Steps:** 160,000 total (100,000 two-voice base + 60,000 three-voice continuation with speaker-embedding expansion; existing voice weights preserved bit-exactly)
- **Wall clock:** ~21 h for the continuation phase (75,471 s logged)
- **Recipe:** batch ≤9000 frames / ≤32 utterances, lr 3e-4 (warmup 1000, half-life 100k), grad clip 10, GAN from step 8000 (ratio 0.7, ramp 3000, feature matching 30), teacher forcing held 3000 then ramped to 0 over 7000, seed 20261113
- **Annotation:** Mandarin CTC phoneme recogniser (`lyonlu13/wav2vec2-large-zh-singing-phoneme-ctc`) for forced alignment; QC gates on vowel voicing, alignment confidence, phone duration, speaking rate
- **No pretrained weights are loaded by the speech model.** The recogniser is used offline for annotation only; an ASR model (faster-whisper) is used offline for evaluation only.

## Evaluation

Validation split (86 utterances, predicted durations/pitch — not teacher-forced), step 160,000:

| Metric | Value |
|---|---|
| Mel L1 (predicted) | 0.539 |
| STFT L1 (predicted) | 1.211 |
| Mel L1 (teacher-forced) | 0.495 |
| Pause accuracy | 97.3% |
| Voicing accuracy | 96.0% |
| Duration length ratio | 0.975 |
| Pitch error | 1.26 semitones |
| Pitch spread ratio | 1.03 |

ONNX parity: max relative waveform error 0.0033 vs PyTorch across 5 sentences × 3 voices; durations bit-identical. CPU speed (ONNX Runtime, 4 threads): 50–53× real time.

Intelligibility: teacher references were screened with faster-whisper CER = 0 for all three voices. Model-output CER evaluation is reproducible via `python -m tiny_voca.evaluate`.

## Ethical considerations

- All three voices are **synthetic designs** (text-described timbres rendered by Qwen3-TTS), not clones of real people. No human voice recordings are included in the training data or the release.
- The model cannot clone voices; it only reproduces its three fixed synthetic timbres.
- Synthetic speech should be disclosed as such in downstream applications.

## Limitations

- Naturalness is below large neural TTS models; the trade-off is 4.5M parameters and CPU real-time inference.
- Text normalization is minimal (pypinyin defaults for numbers/dates); no English fallback.
- Tone sandhi is handled by pypinyin's dictionary, not by a learned prosody model; occasional mis-tones on rare polyphones.
- Trained on read-style synthetic speech; conversational/emotional expressiveness is limited.
