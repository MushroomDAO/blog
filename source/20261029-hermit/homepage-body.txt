What Hermit gives you out of the box
Hermit is an open-source framework with
one training loop
for harness adapters. Bring your tasks and feedback; choose a learning method or write your own. It provides shared infrastructure for:
One Trainer for every method: rollouts, judge feedback, an Evolver step, a checked commit, the next version
Built-in evolution methods and a shared interface for your own Evolver
Adapters as files in a git tree: inspect every version, roll back, ship the final one
Deploy workspaces for Codex, Claude Code or Pi, or export supported contents as a native plugin for compatible hosts
Adapter specification checks and versioned updates, with sandboxing for supported learner programs
Any model backend by reference: Fireworks, OpenAI, Anthropic, DeepSeek, vLLM, SGLang, Ollama

Why a harness adapter
Need
Agents meet scenarios their harness was not written for: a new domain, a new tool, a stream of tasks whose rules only show in the feedback. They should
keep learning in deployment
.
Today
Two ways to adapt an agent:
edit its harness by hand
, which does not scale and does not learn, or
fine-tune the model
, which is expensive, opaque, and tied to one model.
Why
A harness adapter puts the learnable part
outside
the agent: an instruction file, skills, tools, a world model of the venue. The base stays frozen, the adapter trains from feedback, and the same adapter moves between compatible harnesses.
§
How it works: an RL-style loop for harnesses
One loop, many methods
The Trainer runs a batch of tasks through the acting agent with the current adapter, scores them with your judge, and hands the trajectories and feedback to an Evolver. The Evolver proposes a new adapter; the Trainer checks it against the template and commits it as the next version.
From the command line
Or write your own loop
Implement your update logic in an Evolver. The Trainer manages specification checks, versioning, run records and evaluation support.

Get started
Requires Python 3.12+ and Git.
From source (recommended)
Clone the repository to run examples, reproduce recipes and develop your own evolution methods.
git clone https://github.com/Infini-AI-Lab/hermit.git
cd hermit
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
hermit --help
Also available on PyPI
Install the framework CLI and bundled adapter templates in your Python environment:
python -m pip install hermit-harness
hermit --help
The included examples and benchmark recipes use files from the source checkout. See
Installation
for method-specific dependencies.
